# v0.9.2 更新记录

发布日期：2026-11-06

## 调整

- 去掉主体背景上的横向网格装饰线
- 去掉左侧竖向强调装饰线
- 背景恢复为干净的深色/浅色表面渐变

## 保持不变

- 四角全圆角胶囊轮廓
- fly-island 风格配色、顶部高光、彩色功能圆点和脉冲
- 560ms `cubic-bezier(0.16, 1, 0.3, 1)` 过渡
- 内容淡入、动态模糊、闲置半透明和所有功能

![干净背景](../images/fly-compact.png)

## 验证

- Compact / Expanded 背景均无横竖装饰线
- 构建 0 警告 0 错误，测试 11/11 通过
