# v0.11.0 更新记录

发布日期：2026-11-06

## 第三方模型供应商

AI Agent 设置中新增供应商预设：

| 供应商 | 地址 | 默认模型 |
| --- | --- | --- |
| 自定义 / OpenAI 兼容 | 手动填写 | 手动填写 |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| Kimi（Moonshot） | `https://api.moonshot.cn/v1` | `kimi-latest` |
| GLM（智谱） | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |

- 点击预设自动填入地址和默认模型
- 地址/模型仍可手动修改
- 每个供应商使用同一份 API Key 输入框
- 需求中的 `gml` 按 **GLM（智谱）** 实现；如不是 GLM，请选“自定义”

## 协议适配

- DeepSeek / Kimi / GLM 预设强制使用 OpenAI-compatible 协议
- 修复 GLM 的 `/api/paas/v4` 被误判成 Ollama 的问题
- OpenAI-compatible URL 支持任意 base path：
  - 根地址 → `/v1/chat/completions`
  - `/v1` → `/v1/chat/completions`
  - GLM `/api/paas/v4` → `/api/paas/v4/chat/completions`
- 模型列表请求同样适配 `/models`

## 保留

- Agent 独立 API 地址 / 模型 / Bearer API Key
- 留空回退本地模型
- Enter 发送、Shift+Enter 换行、IME 候选确认不误发送

## 验证

- 使用 mock GLM 服务验证：
  - 请求路径为 `/api/paas/v4/chat/completions`
  - 请求头包含 `Authorization: Bearer glm-secret`
  - Enter 发送成功
- 构建 0 警告 0 错误，测试 11/11 通过
