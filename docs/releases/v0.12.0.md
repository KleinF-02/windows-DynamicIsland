# v0.12.0 更新记录

发布日期：2026-11-06

## Agent 模型切换按钮

Agent 面板右上角新增模型按钮：

- 默认显示 **本地模型**
- 点击可切换：
  - 本地模型
  - 自定义 API
  - DeepSeek
  - Kimi
  - GLM
- 切换后立即用于下一条消息
- 选择会立即持久化到 `%LOCALAPPDATA%\DynamicIsland\settings.json`
- 菜单内可直接打开 Agent API 设置

选择本地模型时忽略 Agent 专用 endpoint/key，始终使用共享本地模型配置。

## 保留

- Agent 独立 API 地址 / 模型 / API Key
- DeepSeek / Kimi / GLM 供应商预设
- Enter 发送、Shift+Enter 换行、IME 候选确认不误发送
- 文件/图片输入与本地模型回退

## 验证

- 通过 UI 切换 GLM 后，设置文件写入：
  - `AgentApiProvider=glm`
  - `AgentApiEndpoint=https://open.bigmodel.cn/api/paas/v4`
  - `AgentApiModel=glm-4-flash`
- 切换菜单可正常打开
- 构建成功，测试 11/11 通过
