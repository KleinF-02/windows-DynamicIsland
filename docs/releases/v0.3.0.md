# v0.3.0 更新记录

发布日期：2026-11-05

## 重点更新

### 各功能区停留策略统一

| 功能区 | 停留规则 |
| --- | --- |
| 常用软件 | 悬停保持；移出收起 |
| Calendar | 悬停保持；移出收起 |
| 待办事项 | 输入框聚焦期间保持；失焦后恢复悬浮收起 |
| 翻译 | 输入框聚焦/中文 IME 输入期间保持；失焦后恢复 |
| AI Agent | 输入框聚焦/中文 IME 输入期间保持；失焦后恢复 |

手动“固定窗口”始终优先于临时保持。

### 分辨率自适应

- 按当前显示器工作区计算最大可用尺寸
- 低分辨率、高 DPI（例如 200% 缩放）下，翻译 / Agent 大工作区等比缩小
- 常规 1080p / 1440p 保持 `720 × 560` 工作区
- 不再出现窗口底部或左右超出屏幕的情况

### 动画流畅度

- 展开动画根据尺寸差在 `300–420ms` 之间自适应
- 收起动画保持 `360ms`
- 原生 HWND 的宽度和高度同步到同一条缓动曲线，减少横向跳变和末尾卡顿
- 大工作区切换不再突然弹开

## 修复

- 翻译输入中文时，输入法候选窗/窗口失活可能导致窗口收起
- 高 DPI 或小屏下工作区被裁切

## 构建与测试

- 构建 0 警告 0 错误
- 测试 11/11 通过
- 自包含 Windows x64 发布
