# v0.7.0 更新记录

发布日期：2026-11-05

## 重点更新

### AI Agent 视觉输入

- 支持 PNG、JPG/JPEG、WEBP、GIF、BMP
- 图片会自动等比缩放到最长边 1600px，并转为 PNG 后发送
- 同时支持最多 3 个附件；图片和文本文件可以混合上传
- 聊天记录只显示图片文件名，不展示 base64 或图片全文

### 协议适配

- **Ollama**：图片放在 `/api/chat` 的 `images` 数组中
- **OpenAI 兼容**：图片使用 `image_url` content part，格式为 `data:image/png;base64,...`
- 视觉输入只随当前用户消息发送，不进入后续 18 条历史消息

### 文件格式扩展

- 文本/代码：txt、md、json、csv、log、xml、yaml、cs、ps1、py、js、ts、html、css、sql 等
- Word：`.docx`
- Excel：`.xlsx`（读取工作表和单元格文本）
- PowerPoint：`.pptx`（读取每页文字）
- PDF 暂不支持

### 限制（适配 27B 级本地模型）

- 最多 3 个附件
- 文本最大 4 MB；图片最大 12 MB；Office 文件最大 16 MB
- 单文件最多读取 24000 字，合计最多 48000 字，超出截断
- 图片不计入字符数

## 使用提示

本地模型必须支持视觉输入。对于 `qwen3.6-27b-awq` 这类模型：

- 如果是 Ollama，确认模型已加载视觉投影/多模态能力；
- 如果是 vLLM / LM Studio 的 OpenAI 兼容服务，确认所选模型支持 `image_url` 内容格式；
- 在设置中填写实际模型名，避免自动选中不支持视觉的模型。

## 验证

- 图片上传后显示为“图片 · 文件名 · 大小”附件
- mock Ollama 请求确认包含 `images` 和 PNG base64
- 聊天记录只显示文件名
- 构建 0 警告 0 错误，测试 11/11 通过
