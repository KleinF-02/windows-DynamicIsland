# v0.2.0 更新记录

发布日期：2026-11-05

## 重点更新

- **AI Agent 与翻译统一窗口策略**
  - 鼠标指针在功能区内时保持大工作区展开
  - 鼠标移出功能区/窗口后按普通悬浮规则收起
  - 不自动改变右下角固定状态
  - 手动固定后才会持续保持展开
  - 收起、切换标签后重新展开，对话和输入内容仍在

## 其他改进

- 翻译和 AI Agent 共用 `IsWorkspaceActive` 判定，避免两套行为分叉
- 统一大工作区尺寸为 `720 × 560`
- 补充版本管理文档，明确后续每次迭代递增版本号并保留历史标签
- 保留 `v0.1.0` 和 `v0.1.0-dev.*` 历史版本，不移动、不删除
