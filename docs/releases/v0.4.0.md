# v0.4.0 更新记录

发布日期：2026-11-05

## 重点更新

### 动态模糊 + 渐隐过渡

- 状态切换（胶囊 ↔ 展开）在内容层叠加短时 `BlurEffect`
- 功能区切换时新内容从半透明渐入
- 模糊只作用于内容，胶囊背景、边框和阴影保持清晰
- 模糊动画结束后立即移除 Effect，不留下持续性能开销

### 60fps 动画

- 窗口宽度、高度、位置动画目标帧率设为 60fps
- 功能内容渐入、模糊动画同样按 60fps 调度
- 展开时长继续按尺寸差在 300–420ms 自适应
- 大工作区、悬停展开和收起共用同一条原生窗口尺寸同步曲线

### 性能降级

- 检测 `RenderCapability.Tier`
- GPU 层级低于 2（软件渲染、部分远程桌面）时自动跳过模糊，只保留渐隐/缩放，避免掉帧
- 模糊峰值限制在 3.5–4.5 半径、240–260ms，避免大面积长时间模糊

## 构建与测试

- 构建 0 警告 0 错误
- 测试 11/11 通过
- 自包含 Windows x64 发布
