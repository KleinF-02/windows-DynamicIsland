## 0.2 — 真正“有用”的岛（下一阶段）

优先级从高到低：

- [ ] **媒体会话**：WinRT `GlobalSystemMediaTransportControlsSessionManager`
  - 封面、标题、艺术家
  - 播放 / 暂停 / 上一首 / 下一首
  - 播放进度和音量
  - 音乐播放时自动切换为媒体胶囊
- [ ] **显示器选择**：`Screen.AllScreens` + `PreferredScreen`
  - 设置页下拉框
  - 显示器热插拔后重新定位
  - 顶部 / 底部 / 鼠标所在屏幕策略
- [ ] **Outlook Web / Microsoft Graph 日历**：不依赖桌面版 Outlook 的 OAuth 方案
- [ ] **通知监听**：`UserNotificationListener` 或通知镜像
  - 应用图标、标题、正文
  - 多条通知队列和聚合
  - 免打扰时段
- [ ] **全局快捷键**：`RegisterHotKey`
  - 显示 / 隐藏
  - 展开 / 收起
  - 播放 / 暂停
- [ ] **视觉打磨**
  - 亚克力 / Mica 背景选项
  - 更接近 iOS 的弹簧曲线（自定义 `EasingFunction`）
  - 多显示器 DPI 切换动画
  - 主题色跟随系统强调色

验收标准：连续播放 30 分钟音乐，CPU 平均 < 1%，切换歌曲 UI 不闪烁；双屏不同缩放拖拽后仍居中。
