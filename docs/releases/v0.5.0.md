## iOS 灵动岛动画分析

iOS 灵动岛的核心不是简单的淡入淡出，而是：

1. **连续形变**：胶囊和展开态共用一个可连续变化的圆角形状，尺寸/圆角一起变化；
2. **弹簧动画**：尺寸和内容跟随阻尼谐振子，展开有轻微回弹，收起通常平滑收敛；
3. **mask 揭示**：内容通过随形状变化的圆角遮罩逐步露出，而不是直接切换视图。

WPF 可以复刻这三点的**核心机制**，但受透明分层窗口、HWND 尺寸布局和 WPF 内容树限制，达不到 Core Animation 那样任意单形状连续形变的完全一致效果。

## 本版本实现

### 连续形变

- `Shell` / `ShadowBorder` 圆角随状态在 `23 / 22 / 20` 间连续变化
- 窗口宽高继续连续动画，不切换到另一套窗口
- 圆角、mask、窗口宽高、原生 HWND 共用同一条弹簧进度

### 弹簧动画

- 新增 `SpringEasingFunction` 阻尼谐振子
- 展开：轻微回弹，340–460ms 按尺寸差自适应
- 收起：临界阻尼，380ms，不回弹
- 原生窗口宽高继续 16ms 同步

### mask 揭示

- 胶囊 ↔ 展开时，`ContentRoot.Clip` 使用同尺寸圆角矩形
- 内容从约 16% 高度逐步揭示到完整高度，收起反相
- 结束立即清除 Clip，不影响后续输入/滚动/命中测试

### 保留

- 动态模糊 + 渐隐
- GPU 层级低时跳过模糊的性能降级
- 60fps 目标帧率

## 已知限制

- WPF 的内容树仍是 Compact / Expanded 两套视图，mask 揭示是近似而非 iOS 的单一连续形状
- 透明分层窗口的尺寸仍由 HWND 驱动，无法像 Core Animation 一样任意改变窗口轮廓
- 弹簧回弹幅度已保守设置，避免超出工作区或造成窗口闪烁
