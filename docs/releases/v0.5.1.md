# v0.5.1 更新记录

发布日期：2026-11-05

## 修复

- 修复 AI Agent 输入框只获得焦点、没有输入文字时，鼠标移出功能区后窗口仍不收起
- 翻译 / Agent 的保持条件从“输入框聚焦”改为“实际输入活跃”
- 每次按键或文本变化将保持窗口延长 2 秒
- 停止输入 2 秒后，如果鼠标仍在功能区外，恢复普通收起
- 未输入文字时，仅聚焦不会阻止鼠标移出收起

## 保留

- 中文输入法输入期间仍会通过按键/文本事件持续延长保持，避免输入中文时被收起
- 手动“固定窗口”仍然优先
- 动态模糊、渐隐、弹簧形变和 mask 揭示不受影响

## 验证

- Agent 空输入聚焦 → 鼠标移出 → 正常收起
- Agent 输入文字 → 鼠标移出 → 约 2 秒内保持；停止输入后自动收起
- 构建 0 警告 0 错误，测试 11/11 通过
