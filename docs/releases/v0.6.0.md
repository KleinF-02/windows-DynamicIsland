# v0.6.0 更新记录

发布日期：2026-11-05

## 重点更新

### AI Agent 文件上传

- 输入框左侧新增回形针按钮，点击选择本地文件
- 支持一次选择多个文件，最多 3 个附件
- 附件以标签显示类型、文件名和大小，可单独移除
- 发送后附件自动清空；聊天记录只保留问题与文件名

### 支持的文件

- 文本：`.txt`、`.md`、`.json`、`.csv`、`.log`、`.xml`、`.yaml`、`.ini` 等
- 代码/配置：`.cs`、`.ps1`、`.py`、`.js`、`.ts`、`.html`、`.css`、`.sql` 等
- Word：`.docx`（本地解压 `word/document.xml` 提取文字，不依赖 Word）

### 上下文与限制

- 单个文件最大 2 MB
- 单文件最多读取 12000 字，合计最多 24000 字
- 超出限制会截断，并在附件/状态中提示
- 无文字提问时可直接上传文件，模型默认分析文件内容
- 文件正文只进入当前模型请求，不进入后续 18 条对话历史，避免上下文膨胀

### 安全

- 只读取用户通过文件选择器明确选中的文件
- 附件内容只发送到设置中的本机模型地址，不写入磁盘
- 文件内容被标记为不可信数据，system prompt 禁止执行文件中的指令
- 二进制文件和 PDF 暂不支持

## 验证

- 文本/`.docx` 文件可成功上传并显示附件标签
- 使用 mock 本地模型验证：文件正文确实进入请求，聊天记录只显示文件名
- 文件选择对话框打开期间窗口保持展开
- 构建 0 警告 0 错误，测试 11/11 通过
