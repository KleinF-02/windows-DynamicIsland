# v0.10.0 更新记录

发布日期：2026-11-06

## AI Agent API 配置

设置页新增 **AI Agent API（可选）**：

- **API 地址**：支持 OpenAI-compatible API 或带鉴权的 Ollama
- **模型名**：Agent 可独立于翻译使用不同模型
- **API Key**：以 `Authorization: Bearer <key>` 发送，使用密码框输入

留空 API 地址 / 模型名时，Agent 自动回退到上方本地模型配置，不影响现有本地模型用法。

API Key 只保存在本机 `%LOCALAPPDATA%\DynamicIsland\settings.json`，不会写入日志，也不会发送到未配置的 endpoint。

## Enter 发送

- **Enter**：发送消息
- **Shift+Enter**：插入换行
- **Ctrl+Enter**：仍可发送
- 中文输入法组合输入期间按 Enter 只确认候选词，不会误发送

## 验证

- 使用 mock OpenAI-compatible API 验证：
  - 请求发送到配置的 `/v1/chat/completions`
  - 请求头包含 `Authorization: Bearer test-secret`
  - Enter 能触发发送
- 构建 0 警告 0 错误，测试 11/11 通过
