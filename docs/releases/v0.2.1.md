# v0.2.1 更新记录

发布日期：2026-11-05

## 修复

- 修复 AI Agent 输入中文时窗口无法保持展开的 bug
- Agent 输入框获得焦点后，即使 IME 候选窗导致窗口失活、鼠标移出功能区，也保持大工作区展开
- 输入框失去焦点后才恢复普通悬浮收起规则
- 手动“固定窗口”状态不受影响
- 切换离开 Agent 标签时清理临时输入保持状态，避免窗口之后无法收起

## 验证

- Agent 输入框聚焦 → 鼠标移出 → 窗口保持展开
- 输入框失焦 → 鼠标移出 → 窗口按普通规则收起
- 切换标签后可正常收起/展开
- 构建 0 警告 0 错误，测试 10/10 通过
