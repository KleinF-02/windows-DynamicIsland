# v0.12.1 更新记录

发布日期：2026-11-06

## 修复

- 修复已填写 Agent API 地址/模型/Key，但 provider 仍为 `local` 时，请求被强制走本地模型的问题
- 旧配置升级：`provider=local` 且已有 Agent API 地址/模型时，自动升级为 `custom`
- 设置页编辑 Agent API 地址或模型时，自动从“本地模型”切到“自定义 API”
- 选择“本地模型”时清理旧的 Agent endpoint/model，确保保存后不会再次被识别为远程配置

## 现在的行为

- 默认：本地模型
- 填写自定义 API 地址/模型：自动使用远程 endpoint
- 选择 DeepSeek / Kimi / GLM：使用对应预设
- Agent 面板模型按钮与设置页保持同步

## 验证

- 使用 `provider=local` + 非空 Agent endpoint/key 的旧配置启动
- 实际请求命中 remote `/v1/chat/completions`
- 请求头包含 `Authorization: Bearer migration-secret`
- 构建 0 警告 0 错误，测试 11/11 通过
